User Manager

یه اپلیکیشن تک‌صفحه‌ای که هدفم از ساختنش تمرین کار با فرم، دریافت داده از یک API و آشنایی با مفاهیم پایه‌ی تست نرم‌افزار بود.

برای بخش فرم، از React Hook Form برای مدیریت فرم و داده‌های ورودی، Zod برای اعتبارسنجی سمت کلاینت، Axios برای ارسال اطلاعات به سرور و TanStack Query برای مدیریت Server State استفاده کردم.

توی بخش لیست کاربرا، اطلاعات رو با Axios دریافت کردم و به کمک TanStack Query حالت‌های مختلف دریافت داده، مثل Loading و Error رو مدیریت کردم و اگه داده با موفقیت دریافت می‌شد، نمایشش می‌دادم. برای تست کامپوننت‌ها هم از Vitest و React Testing Library استفاده کردم.

React · TypeScript · Tailwind CSS · React Hook Form · Zod · Axios · TanStack Query · Vitest · React Testing Library
